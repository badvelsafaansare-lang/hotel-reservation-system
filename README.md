# Hotel Reservation System

A Java-based Hotel Reservation System that allows users to book rooms, manage reservations, search bookings, calculate bills, and cancel reservations through a simple menu-driven interface.

## Features

- Book a hotel room
- Select different room types
- Enter customer details
- Assign room numbers
- Check room availability
- Calculate total bill based on number of nights
- Generate unique Booking ID
- View all bookings
- Search booking by Booking ID
- Cancel existing bookings
- Menu-driven user interface
- Handles multiple reservations

## Room Types

| Room Type | Price per Night |
|---|---:|
| Single | Rs. 1500 |
| Double | Rs. 2500 |
| Deluxe | Rs. 4000 |

## Technologies Used

- Java
- Scanner
- ArrayList
- Loops and Conditional Statements
- Git & GitHub

## How It Works

1. Select an option from the main menu.
2. Choose a room type and enter customer details.
3. Enter the room number and number of nights.
4. The system checks whether the room is already booked.
5. A unique Booking ID is generated.
6. The total bill is calculated automatically.
7. Users can view, search, or cancel bookings.
8. The system continues running until the Exit option is selected.

## Project Purpose

This project was developed to practice Java programming concepts such as ArrayList, loops, conditional statements, searching, data management, input handling, and menu-driven programming.
